# Lock In

A personal dashboard for goals, daily tasks, habits, and focus sessions. Built with Next.js App Router, TypeScript, Tailwind CSS, and shadcn/ui-style source components.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Run `npm run build` to generate the static site in `out/`. The Next.js project can be deployed on Vercel from the repository root.

Progress is stored in the current browser's `localStorage`. It does not sync between browsers or devices. Clearing site data removes the progress saved in that browser.
